# 视觉分析与评分 v1.0

ChatCut `inspect_asset` 按源素材时间抽帧，保留工具返回的时间标签；单次最多 25 帧。30 秒以内通常取 8–16 帧，30–60 秒至少约 16 帧；超过 60 秒取 25 帧，再用交错时间点或按画面变化分段补抽，避免长视频只由一张稀疏表代表。大幅扬被、抛枕、快速抓捏等动作，在动作前、中、后另以约 0.15–0.5 秒间隔密集抽帧；镜头平移和主体运动应分开判断。首次学习的密集抽帧仍只支持候选区间，不能因此宣称逐帧切点已经验证。逐条记录主体、床品整体或细节、人物/手、背景物件、景别、机位与运动、光线、色彩、构图、动作和卖点。只写可见证据；材质成分和工艺不可仅凭画面认定。候选片段时间码属于源素材，初学为 `coarse`，剪辑前以 0.1–0.2 秒密度复查并标 `frame_verified`。

若同一条素材可见不同产品或颜色，记录每一种可见内容并将素材标为 `mixed`；不得因为文件夹名称就把全片当作该目录单品。严格单品检索排除这类素材。只有用户明确允许混剪或跨色时，才将其作为混合候选并在剪辑前逐帧复核具体区间。

未来的大幅或重复运动需单独建立 `motion_events`：先用概览圈出每次完整动作，再在每段附近按源时间递进缩小范围，直到动作开始和结束都由相邻源帧夹定；重复动作逐个周期记录，不能只标一个总区间。检查预备动作、峰值、完成及回弹，明确主体运动与相机运动。记录边界的源时间码、动作描述、单次/重复/连续模式、周期序号和帧证据。看不到准确边界时只记 `coarse` 并说明限制，不能填 `frame_verified`。

审美分数为模型主观评价：构图、光线、色彩、面料呈现、镜头运动、品牌匹配各 0–10，综合分取六项平均并保留理由。无法判断的维度写明，不虚构分数。标记抖动、模糊、遮挡及可能适合变速的瞬间。`suggested_playback_rate` 仅为建议，实剪时验证动作完整性。
