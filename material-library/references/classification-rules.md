# 分类规则

2026-11-04 用户确认：`80支沙漠灰` 为型号“80支”与颜色“沙漠灰”；`天丝棉描花` 为型号“天丝棉”与花色“描花”。`120支绿色` 内深浅绿是不同颜色，暂命名“深绿”“浅绿”。同框两色标 mixed，通过 asset_product_mentions 关联两色，默认单色检索排除。单色镜头按实际画面绑定颜色。

同一物理目录含多个颜色时，可创建数据库逻辑分类，relative_folder_path 用原目录加 `#visual:深绿` 或 `#visual:浅绿`；这是分类键，不是实际文件夹。assets 的绝对路径和相对路径始终指向原文件。不创建这些逻辑目录。相同指纹仅更新时间或同目录改名时保留已确认颜色；内容被替换时撤销视觉确认并重新分析。

视频沿用实际相对路径的前两级作为 `series`、`category_name`；产品与颜色只从 `classification.json` 的词典或明确映射解析。产品名称按长度优先匹配，再要求剩余部分完整命中颜色词典。空格仅在匹配时忽略，原始分类名和路径保持原样。无法解析时将分类标为 `pending`，不得猜测。新增分类先核对实物，再扩充词典或 `name_mappings`。允许用户按系列、型号族、型号、颜色或完整分类限定查询；范围内仍逐条保持产品身份，不把不同颜色或型号当成同一单品。

未来视频若只放在根目录或单层目录，也登记原路径与文件信息，用 `[root]` 或实际单层目录名作路径占位，分类保持 `pending`；不可凭“开箱”等文件夹名字直接确认为内容角色或产品。

图片、PDF、音频按扩展名识别媒体格式，但**不按扩展名或文件名推断内容角色**。先保留 `unclassified/pending`。检查画面、文字或试听后，确认是开箱、认证文件、音效或其他；不能判断时列出路径和待确认问题向用户提问。认证素材记录所对应的产品和可见证据；不能确定适用型号或广告宣称时保持待确认。通用音效可不绑定产品，但需确认声音内容与适用画面。混合视频记录所有可见产品及证据，默认单品搜索排除，只有明确允许时才作为混合画面候选。
