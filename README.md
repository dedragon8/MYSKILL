## 使用

按需将完整技能目录放到本地技能目录（例如 `~/.codex/skills/`），保留其中的 `references/`、`scripts/` 和 `agents/`。使用前阅读对应 `SKILL.md`，按自己的环境调整本地路径、项目与文档目标。

这些技能保留作者的品牌规范和工作流；ChatCut、飞书 CLI、本地语音模型等依赖按对应说明另行配置。仓库不包含原始视频素材、素材数据库、模型权重及运行环境。

## 更新

此仓库由作者本地三个技能目录同步维护，包含配套脚本、参考资料和案例图片，排除旧备份、缓存及系统文件。

公开版本将个人账号绑定、飞书文档与消息标识、本机用户名和工程标识替换为通用说明或占位符；本地原稿保留不变。使用飞书通知功能时需取得当前用户授权并核验身份。
