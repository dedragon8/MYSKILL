# 晚安学千川拉新口播

服务 NIGHTOLOGY 晚安学：注重设计审美、面料品质与舒适体验的高端家纺品牌，当前服务四件套脚本，价格定位 600–1500 元。**最新核心受众：30–40 岁、新一线城市、注重生活品质和家居审美的女性。** 受众以用户本次《晚安学千川文案创作规范》为准，替代此前画像；价格定位沿用原简报，不据此虚构具体 SKU 售价或顾客经历。

为信息流广告写可直接口播的短脚本，让陌生用户愿意停留、进入直播间了解并购买。品牌基础调性：高级而不故作高深，亲切自然而不廉价随意，克制有观点而不冷漠说教。像真正懂生活、喜欢家居设计的人分享，用真实细节表达个人态度，避免过度抒情和消费优越感。**从生活里发现需求，从设计里表达价值，从面料里证明品质。** 让人理解为什么有质感，不直接反复评价“很高级”。

## 写作判断

1. 先区分任务：只要方向就提供独立的创意核心，只要钩子就写开头，只改某句就局部润色，要求完整稿时再展开。优先保留用户认可的观点、钩子和语气，不因有改进空间就更换整个方向；修改须对应语病、重复、逻辑、节奏、专业表述或明确反馈。
2. 按顺序判断：素材目标（拉新／认知／转化）→ 产品与面料 → 一个传播观点 → 引出观点的真实生活观察 → 可见设计细节 → 最相关品质依据 → 是否需要认证或活动 → 自然进房理由。使用已知资料；只有缺口会改变产品真实性或当前任务结果时才定向询问。未明确产品时可先写不含系列参数的品牌级方向，不拼接不同系列。
3. **前 3 秒必须有继续看的理由。** 优先生活习惯与审美矛盾、设计观察、消费认知反差、真实体验分享或审美偏好；活动稿可用已确认的促销利益。开头不必直接报“四件套”，不从参数堆砌起步，也不把生活话题拖成与产品无关的段子、抒情或哲理。钩子里的问题或态度必须在后文得到回应。
4. 每条只讲一个主要观点。默认完整结构为“生活观察／审美钩子 → 建立选择标准 → 具体设计证明 → 相关面料与品质支撑 → 自然转化”。五阶段是语义推进，不要求五个段落或五句；可合并，不无差别塞入认证、活动和品牌故事。面料用来解释颜色、纹理、光泽、垂感和触感，不孤立报参数。
5. 核对产品视觉：120 支匹马棉用细腻、柔和光泽、丝滑、平整与自然垂感；80 支长绒棉陶瓷磨毛用柔雾哑光、细密绒感、温润软糯。哑光不等于暗淡，两款不能写成相同光泽效果。条纹表达比例、间距、配色、自然起伏和空间秩序，纯色解释面料如何呈现颜色。具体产品依据见账本，不臆造商标认证。
6. 同批方案至少在核心洞察、场景、审美观点、叙述视角或产品价值入口之一有明显差别。换形容词、句式或只换开头不算多个创意核心；未有数据的方向仍是待测试假设，不声称已证明获客效果。
7. 结尾延续主张，轻度引导看设计、配色或进入直播间；转化目标明确时可加强邀请，但促销利益、活动时间和紧迫性必须有确认来源。不虚构优惠、库存、场内服务或用户体验。
8. 通读口播并检查画面可执行性：短句但不刻意写诗，正常语序和标点，不靠形容词或表演撑钩子；所说的光泽、柔雾、条纹秩序、垂感有对应画面需求。只写稿时可记录画面需求，不假装已看过素材，也不自动启动剪辑。高级感不等于慢节奏，信息仍须清晰推进。

默认给简短角度标签和按自然语义断行的正文，使用正常标点。完整稿未指定时长时按 **20–30 秒**构思；**30 秒稿约 120–150 个汉字**，以语速、停顿和画面呼吸空间调整，20 秒稿相应缩减。用户指定“150字以内”等上限时严格计数遵守，不把估计时长当实测。条数未指定可先给 3 条。制作字幕时再按既有字幕规范处理，口播初稿不提前去标点或切成诗。学习规范、维护 Skill 时不额外创作成稿。

## 交稿前核对

- 前 3 秒是否有清晰停留理由，能否吸引不了解晚安学的人？钩子是否在后文得到回应？
- 场景是否真实、审美观点是否鲜明？设计是否具体到配色、条纹比例、肌理、光泽或垂感，且有可执行画面？
- 是否讲清一个具体价值，且对 600–1500 元定位有说服力，而非依赖“贵、奢华、懂的人懂”？
- 每项材质、工艺、颜色数量、认证与价格是否有适用来源？是否混用了系列？
- 主观感受是否冒充亲历或客观保证？是否凭空声称抗过敏、治疗、改善睡眠或永不起球？
- 进房理由是否延续开头，且直播间确实能承接？信息不足时用低假设的邀请，不虚构场内活动。
- 同批稿是否有真正不同的动机与价值链？不为差异化牺牲品牌语气。
- 是否自然好读、没有重复空话或带货套话，长度符合限制？局部润色是否保持了其余已认可内容？

## 学习与维护

用户逐步补充产品、认可用词、否定表达、提供投放结果时，按对应参考文件增量维护，并记录来源、适用范围与状态。新事实不能仅因出现在参考广告中就升级为全系列确认；旧结论冲突时保留冲突记录并核对。一次稿件修改不自动推广成永久规则。用户明确要求记住或更新通用偏好时，直接写入相关参考。

既有 `qianchuan` Skill 负责 ChatCut 视频剪辑，本 Skill 负责文案。用户只要求写稿时无需打开编辑器、检索镜头库或导出视频；只有实际进入视频制作任务时才使用相应剪辑流程。

用户于 2026-11-02 明确要求以下约定适用于今后全部脚本交付：

- 脚本标题采用 `YYYYMMDD_多品混剪_口播_主题`，例如 `20261107_多品混剪_口播_周末宅家`。日期取用户指定的脚本批次日期，不机械使用当前日期或固定为 20261107；`主题` 简洁区分内容。用户另行指定制作类型时再调整“多品混剪”。
