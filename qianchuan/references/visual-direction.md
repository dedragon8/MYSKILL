# 品牌审美与导演决策

本规范用于 NIGHTOLOGY 晚安学的千川广告。它是用户提供的品牌创意方向，不代表独立核验过的受众或投放结论。其他品牌的任务应先以该品牌的定位和本次要求为准。与已确认成功案例共同使用时，按脚本目标和素材条件判断适用性，不把任一案例的单次做法当作固定模板。

## 品牌定位

- **主要服务品牌**：NIGHTOLOGY 晚安学。
- **品牌定位**：具有现代设计审美的高品质床品品牌。
- **核心受众设定**：新一线城市、30–40 岁、注重生活品质和家居审美的女性。
- **视觉关键词**：现代、克制、精致、舒适、松弛、低调奢华。
- **表达目标**：在实用价值之上呈现审美价值与情绪体验；将床品放进卧室空间设计和生活方式中，而非只作为普通家纺商品陈列。

## 判断画面是否具有高级感

1. **构图**：优先主体明确、层次清晰、留白合理、空间有秩序的镜头。
2. **光线**：优先自然柔和、仍有质感层次的光线；降低明显过曝、死黑或廉价高对比画面的优先级。
3. **色彩**：检查床品颜色与卧室空间的协调；避免无依据地过度饱和、偏色或套用夸张滤镜。
4. **材质**：优先能真实呈现面料纹理、柔软度、垂坠感、光泽与细节的镜头。
5. **运镜**：优先稳定、流畅且有展示目的的运动；避免无意义的推拉摇移和频繁数字变焦。
6. **空间**：观察产品与床、家具、建筑线条、室内光影的关系，让画面体现整体居住氛围。
7. **真实感**：保留面料纹理和产品真实颜色；避免过度锐化、磨皮或特效造成虚假质感。

高级感不能简单等同于慢剪、压暗画面或增加电影黑边。遇到素材质量和品牌调性冲突时，优先保证产品真实、画面清晰，并标记需要人工复核之处。

## 千川广告节奏

**总原则**：同时照顾品牌质感与信息流传播效率。节奏利落、有变化、有视觉吸引力，但不过度刺激。

### 开头

- 前 1–3 秒优先呈现有视觉吸引力、产品辨识度或情绪感染力的镜头，并尽快建立产品或品牌认知。
- 根据脚本选择视觉、材质、审美、场景或反差钩子；不要为了形式感牺牲信息。
- 不默认用夸张转场、闪白、震动或大字轰炸。

### 切点与景别

- 不按固定秒数或逐句机械切镜。综合口播语义、语气、停顿、音乐、画面运动和信息密度决定切点。
- 材质细节可用短镜头强化感知；空间全景与设计展示要留足观看时间。
- 在特写、中景、全景之间建立变化，避免连续使用构图、角度和运动方向高度相似的镜头。
- 一句口播可切多个镜头，一个镜头也可覆盖多句。快节奏不能牺牲产品识别和画面美感。

可参考“视觉吸引 → 信息展开 → 质感强化 → 空间展示 → 购买引导”的呼吸节奏。它不是固定结构；实际顺序、时长和密度由脚本、素材及相关成功案例决定。

## 口播与画面的导演逻辑

判断镜头时，不只看它是否包含对应商品，还要看它能否增强口播的说服力、感受和品牌价值。

| 口播内容 | 优先考虑的画面 |
|---|---|
| 材质、支数、工艺 | 面料微距、纹理、细节和真实工艺展示 |
| 柔软、亲肤、裸睡 | 柔软垂坠、轻柔触摸、自然褶皱等支持感受表达的镜头 |
| 卧室美学、设计、配色 | 空间全景、构图、色彩搭配与床品整体展示 |
| 秋冬舒适、温暖氛围 | 柔和光线、丰盈面料、温暖卧室场景 |
| 品牌理念、生活方式 | 有情绪感染力的空间与产品画面 |
| 活动价格、购买引导 | 产品辨识度高、利益信息清晰的镜头 |

- 不必逐字解释口播；可用情绪、空间和细节建立视觉联想，避免机械重复。
- 优先使用同时表达产品卖点与品牌美学的镜头。
- 不用无法证实的视觉表现暗示未经验证的产品功能；认证、价格和优惠须以本次真实材料为准。
- 素材不足以支撑口播时，明确指出缺口，不假装已有完美匹配。

## 素材选择与候选镜头比较

有多个可用镜头时，依次比较：

1. **语义匹配**：是否真实支持当前口播。
2. **视觉审美**：构图、光线、色彩和质感是否符合品牌。
3. **产品展示**：能否清楚识别产品、材质或设计。
4. **节奏适配**：镜头运动和可用时长是否适合此处。
5. **镜头衔接**：与前后镜头的景别、色彩和运动方向是否协调。

这些维度用于比较候选，不是绝对分数。优先保证语义真实、画面质量与品牌一致性。不要只按文件名或素材顺序选镜头；若 ChatCut 无法充分辨认内容，应抽取关键帧或用视觉分析工具检查实际画面。

## 字幕与品牌文字

口播字幕继续使用 SKILL.md 中已保存的 **9:16、MiSans、位置、字号、阴影和单行居中参数**。以下原则补充审美判断，不改动这些默认参数：

- 字幕是辅助信息，不成为画面视觉主角；避免过度放大、密集堆叠和频繁跳动。
- 保持文字层级清晰、节奏准确、画面整洁；按自然语义断句，避免机械逐字跳动。
- 重要信息可以适度强调，但不默认使用大面积高饱和色块。
- 避开产品关键纹理、设计细节和主体。
- 纯产品展示广告若需要更高级的排版，可另做独立品牌文字设计，不强制套用口播字幕样式；口播字幕仍按默认参数处理，除非用户另有要求。

## 避免作为默认做法

除非用户明确要求，或相关成功案例和本次素材证明适用，否则避免：

- 高频闪白、震屏、夸张缩放、无意义的花哨转场和连续机械快切。
- 过度锐化、过度饱和、明显偏色。
- 过量贴纸、表情符号、促销装饰及大面积遮挡产品的文字。
- 不符合口播语义的随机素材拼接。
- 为所谓高级感无意义地拖慢节奏，或为转化牺牲真实质感和品牌形象。

## 剪辑前的导演决策

正式执行 ChatCut 剪辑前，先在内部方案中回答：

1. 这条广告最重要的传播目标是什么？
2. 开头最有吸引力的视觉信息是什么？
3. 哪些口播需要材质特写，哪些需要空间展示？
4. 哪些镜头最能体现品牌审美？
5. 整体节奏如何变化？
6. 哪些素材不符合品牌方向，应降低优先级？
7. 应参考规则库中的哪几条成功案例？

形成镜头与字幕方案后再执行，不按素材文件顺序机械拼接。方案不必拘泥于固定模板，但应能说明关键镜头为何被选用。

## 导出前的成片检查

- 开头是否有信息流吸引力，并及时让人认出产品或品牌。
- 产品信息清楚的同时，是否保留品牌质感。
- 画面是否支持口播语义；景别、色彩、运动与节奏是否协调。
- 是否存在低质感镜头、无意义特效或素材不足却强行匹配的段落。
- 字幕是否准确、克制、同步且不遮挡主体。
- 产品颜色、材质和设计是否真实；结尾是否完成脚本所需的品牌或转化表达。

审美无法由工具参数单独证明时，检查实际渲染画面，并标记仍需人工复核的部分。
